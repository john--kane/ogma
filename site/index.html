Permission comes first.

Filesystem, environment and network access start denied. Explicit grants define the boundary; Unix file access stays anchored to directory handles.

--allow-read=./src --allow-net=example.com:443

A crash ends the attempt.

The supervisor enforces cancellation and deadlines, monitors resident memory, and terminates the worker process tree. Completed side effects are never silently replayed.

--timeout-ms=30000 --memory-mb=256

Contracts you can inspect.

Versioned IPC and a trusted, opt-in C ABI. Shared contracts generate C#, Rust and TS bindings. Structured diagnostics and tracing make behavior visible.
